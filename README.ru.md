# P90Guard

Серверный античит для выделенных серверов **SCP: Project 90** (BepInEx 6, IL2CPP).

[English version](README.md)

Игра доверяет клиенту множество сетевых команд: выдать себе предметы, поставить HP, «я мёртв», телепорт на точку спавна, команды админ-панели, установка объектов песочницы, подрыв мин. Mirror выполняет их на сервере без проверок, поэтому модифицированный клиент может всё это делать. P90Guard проверяет эти команды на сервере и блокирует те, которые обычный клиент отправить не может.

- Самостоятельный: зависит только от BepInEx и игры. Работает рядом с любыми другими плагинами.
- Каждая проверка отдельно настраивается: `Off`, `Log` или `Block`.
- Опционально: очки, автокик и автобан, собственный бан-лист, вебхук в Discord или JSON.
- Общая сеть читеров (по ключу от владельца сети): читер, забаненный на одном сервере, помечается на других.
- Публичный API (события) для сайтов, ботов и панелей, можно подключить через рефлексию.
- Исправляет баги игры на выделенном сервере: взорвавшиеся гранаты и мины никогда не удаляются на сервере; мёртвые игроки могут бросать гранаты и лечиться (клиент «помнит» предмет в руках).

> **Статус: 1.2.0 (бета).** Все проверки построены по коду игры (какие именно команды и когда шлёт обычный клиент). Разрабатывались и работали на одном сервере. Перед включением автонаказаний посмотрите лог несколько дней.

## Поддерживаемая версия игры

Имена в игре обфусцированы и меняются с каждым обновлением. P90Guard привязан к конкретной сборке:

| P90Guard | Игра | SHA-256 GameAssembly.dll |
|---|---|---|
| 1.0.0 – 1.2.0 | 0.4.2 [F05] | `ba69d16edce7b6fb2362823b8d7285b9905105c648289f0f25cbccdb9973164a` |

При запуске плагин считает хэш `GameAssembly.dll`. На неизвестной сборке он **ничего не патчит** (при `GameHashCheck: "safe"` по умолчанию) и пишет хэш в лог. Так обновление игры не заставит античит блокировать не те команды.

## Установка

1. Установите [BepInEx 6 IL2CPP](https://builds.bepinex.dev/projects/bepinex_be) на выделенный сервер и запустите его один раз.
2. Положите `P90Guard.dll` в `BepInEx/plugins/`.
3. Запустите сервер. Конфиг создастся в `BepInEx/config/P90Guard.json`.

Плагин работает только когда игра запущена с `-batchmode` (выделенный сервер). На клиенте он ничего не делает.

Строки в логе выглядят так:

```
[P90Guard] BLOCKED add_item: Nick (7656119..., Class-D) - gave themselves "Keycard O5", which is not in the Class-D loadout
[P90Guard] SUSPICIOUS cuff_far: Nick (7656119..., MTF) - cuffed Other from 41 m away
```

Они пишутся в консоль и лог BepInEx, а при `LogToFile` ещё и в `BepInEx/P90Guard/logs/ГГГГ-ММ-ДД.log`.

## Проверки

| Проверка | Что ловит | По умолчанию |
|---|---|---|
| `steamid_spoof` | Клиент сообщает чужой SteamID (сравнивается с SteamID транспорта Steam P2P, его подделать нельзя). Так крадут админские ранги и значки. | Block, мгновенный кик |
| `role_spoof` | Клиент запрашивает роль, значок или админ-инструменты чужого SteamID. | Block, мгновенный кик |
| `admin_cmd` | Блокировка раунда вкл/выкл, смена режима раунда, перегенерация карты от не-админа. В игре у этих команд нет проверки прав. В режиме Block ещё и молча не даёт не-админам смотреть чужой инвентарь. | Block |
| `admin_action` | Действие встроенной админ-панели без ранга. Игра его и так отклоняет, проверка только сообщает. | Log |
| `fake_server` | Служебная команда «я выделенный сервер» от клиента. | Log |
| `add_item` | Выдача себе предметов. Обычный клиент делает это только сразу после смены класса и только предметы из набора класса. Также ловит выдачу предметов другому игроку. | Block |
| `clear_inv` | Очистка своего инвентаря без смены класса или чужого инвентаря. | Block |
| `set_hp` | Установка себе HP, отличного от максимума нового класса (один раз на смену класса). | Block |
| `set_dead` | «dead = true/false» без соответствующей смены класса (годмод, фейковая смерть). | Block |
| `set_ammo` | Выдача себе патронов класса, которым игрок только что не стал. | Block |
| `spawn_tp` | Команды позиции спавна без смены класса (телепорт). | Block |
| `force_spectator` | Перевод другого игрока в наблюдатели. | Block |
| `door_close` | Удалённое закрытие двери во время раунда (у команды нет проверки владельца и дистанции). | Block |
| `spawn_tool` | Команды SpawnTool из песочницы (поставить, удалить, двигать, вращать, масштабировать объекты) без инструмента в руках. Каждый поставленный объект пишется в лог с ником. | Block |
| `landmine_far` | Подрыв мины с точкой взрыва далеко от мины (граната в любом месте карты). | Block |
| `cuff_far` | Наручники на игрока дальше `Cuff.MaxDistance` (игра проверяет только на клиенте). | Log |
| `use_missing` | Лечение аптечкой или таблетками, бросок гранаты без предмета. | Log |
| `heal_spam` | Лечение аптечкой чаще, чем позволяет длительность лечения. | Log |

Как работают проверки спавна: каждая смена класса на сервере выдаёт игроку ровно те команды, которые обычный клиент для неё шлёт. Наблюдатель получает 1 позицию, 1 HP, 1 очистку, 1 «мёртв», 1 отложенную позицию. Любой другой класс получает 1 позицию, 1 HP, 2 очистки, 1 «жив», 2 патронов и по одному AddItem на каждый предмет набора. Разрешения сгорают через 120 с. Смены класса в пределах 60 с суммируются, потому что корутина прошлого класса может ещё досылать команды. Админов и серверные плагины, которые сами вызывают эти команды, это не затрагивает.

Только что зашедший игрок в течение `JoinGraceSeconds` только попадает в лог: без блокировок, очков и киков. Исключение составляют проверки подмены SteamID и роли.

Очки, баны и `ExemptSteamIds` используют только SteamID из транспорта Steam, а не тот, что сообщает клиент.

## Настройка

`BepInEx/config/P90Guard.json`. Файл **перечитывается автоматически** через пару секунд после сохранения, рестарт не нужен. Новые проверки из обновлений плагина добавляются в ваш файл автоматически со значениями по умолчанию. Комментарии в JSON разрешены (плагин перезаписывает файл, удаляя комментарии, только когда добавляет новые проверки).

```jsonc
{
  "Enabled": true,
  "GameHashCheck": "safe",          // safe | warn | off
  "AllowedGameHashes": [],          // дополнительные хэши GameAssembly.dll, которым вы доверяете
  "ExemptMinAdminRank": 1,          // админ-ранг (ServerAdmins.json) >= этого не проверяется; 0 = проверять всех
  "ExemptAdminToolsAccess": true,   // игроки со встроенными админ-инструментами не проверяются
  "ExemptSteamIds": [],             // SteamID64 (строки), которые никогда не проверяются
  "JoinGraceSeconds": 30,           // загружающийся клиент только в лог, без блокировок
  "NoSteamIdGraceSeconds": 60,
  "RepeatLogSeconds": 10,           // одинаковое сообщение по одному игроку не чаще этого
  "LogToFile": true,

  "Checks": {
    "add_item": { "Mode": "Block", "Points": 5, "InstantKick": false },
    "cuff_far": { "Mode": "Log",   "Points": 3, "InstantKick": false }
    // ... все проверки из таблицы выше
  },

  "Punishments": {
    "Enabled": false,               // автокик/автобан по очкам. По умолчанию выключено!
    "WindowMinutes": 10,            // очки суммируются за это скользящее окно
    "KickAtPoints": 15,             // 0 = никогда
    "BanAtPoints": 40,              // 0 = никогда
    "BanMinutes": 1440,             // 0 = навсегда
    "BanAfterKicks": 3,             // N-й кик за KickMemoryHours превращается в бан (0 = выкл)
    "KickMemoryHours": 6
  },

  "Webhook": {
    "Url": "",                      // URL вебхука Discord или любой HTTP-адрес; пусто = выкл
    "Format": "discord",            // discord | json
    "OnlyBlockedAndPunishments": true,
    "MaxPerMinute": 20,
    "DiscordMention": "",           // например "<@&123456789>"
    "ServerName": "SCP: Project 90 server"
  },

  "Landmine": { "MaxDistance": 5 },
  "Cuff": { "MaxDistance": 12 },

  "Fixes": {
    "DestroyExplodedGrenades": true,  // false, если это уже делает другой плагин
    "DestroyExplodedLandmines": true,
    "BlockSpectatorItemUse": true     // игнорировать «бросок гранаты» / «лечение» от мёртвых (баг клиента)
  },

  "Messages": {
    "KickSpoof": "Anti-cheat: identity spoofing",
    "Kick": "Anti-cheat: kicked ({reason})",
    "Ban": "Anti-cheat: banned until {until} ({reason})",
    "BanPermanent": "Anti-cheat: permanently banned ({reason})"
  },

  "DisabledPatches": []             // имена классов Harmony-патчей, которые не ставить (для отладки)
}
```

### Режимы проверок

- `Off`: проверка ничего не делает.
- `Log`: команда выполняется, игрок попадает в лог и получает очки.
- `Block`: команда **не** выполняется, игрок попадает в лог и получает очки.

`InstantKick: true` кикает при первом срабатывании независимо от очков (даже при выключенных наказаниях).

### Как лучше включать

1. Несколько дней поработайте с настройками по умолчанию (`Punishments.Enabled: false`) и почитайте лог.
2. Если проверка срабатывает на честных игроков, переведите её в `Log` или `Off` и откройте issue со строкой из лога.
3. После этого включайте `Punishments`.

## Сеть читеров

Серверы с P90Guard ведут общую базу читеров через сеть FLX (flx-scp-project-90.ru).

- **Чтобы подключиться**, получите ключ у владельца сети (Discord FLX) и впишите его в `Network.ApiKey` в `P90Guard.json`. Файл перечитается сам, `pg status` покажет связь. Без ключа ничего не отправляется.
- **Когда админ банит читера** командой `pg cheatban`, в сеть уходит отчёт: SteamID, ник, причина, срок, название сервера и последние срабатывания античита по игроку.
- **Когда заходит любой игрок**, сервер проверяет его SteamID. Если на него жаловались другие серверы, P90Guard предупреждает в консоли, в логе, в вебхуке и на экране у админов на сервере.

**Что отправляется.** SteamID каждого заходящего игрока (только для проверки) и данные выше при `pg cheatban`. Больше ничего: ни чата, ни IP, ни других банов. Отключиться — удалить ключ или поставить `"Network": { "Enabled": false }`. Это предупреждение печатается в консоли при каждом запуске. Если сеть недоступна, сервер играет как обычно.

Команды консоли:

| Команда | Что делает |
|---|---|
| `pg cheatban <ник\|SteamID> <минуты\|perm> <причина>` | Бан за читы здесь и отчёт в сеть |
| `pg unban <SteamID>` | Снять бан и отозвать отчёт этого сервера |
| `pg check <ник\|SteamID>` | Проверить игрока по сети |
| `pg recent` | Последние 20 срабатываний |
| `pg status` | Статус плагина и сети |

Что делать с игроком, на которого есть отчёты, решаете вы (`Network.OnReportedJoin`): `Log`, `NotifyAdmins` (по умолчанию), `Kick`, `Ban`. Кик и бан — только если отчёты от `ActionMinServers` (2) разных **проверенных** серверов, никогда для исключённых игроков и не раньше 10 с после входа. Используется только SteamID подключения, поэтому подменой SteamID чужой аккаунт под отчёт не подставить.

Настройки — секция `Network` в `P90Guard.json` (см. английский README). Протокол для своей сети: [docs/NETWORK_API.md](docs/NETWORK_API.md).

## Бан-лист

`BepInEx/config/P90Guard.bans.json` содержит собственные баны античита. Забаненного игрока кикает примерно через 2 секунды после подключения. SteamID берётся из транспорта, подделать его нельзя. Чтобы разбанить, удалите запись и сохраните файл, он перечитается сам. Если в файле синтаксическая ошибка, плагин пишет об этом в лог и не перезаписывает файл, пока её не исправят. Баны можно добавлять и вручную:

```json
[
  { "SteamId": "76561198000000000", "Nick": "cheater", "Reason": "manual", "By": "admin",
    "Created": "2026-10-01T12:00:00Z", "Until": null }
]
```

`Until` в UTC; `null` значит навсегда.

## API для других плагинов

`P90Guard.Api` использует только простые типы, поэтому подписаться можно через рефлексию, без ссылки на P90Guard:

```csharp
var api = Type.GetType("P90Guard.Api, P90Guard");
api?.GetEvent("Flagged")?.AddEventHandler(null,
    new Action<IReadOnlyDictionary<string, object>>(d =>
        Log.LogInfo($"{d["nick"]} {d["check"]} blocked={d["blocked"]}: {d["details"]}")));
```

- `Flagged` срабатывает на каждое сообщение о нарушении (после ограничения `RepeatLogSeconds`). Ключи: `steam_id` (ulong), `nick`, `role`, `check`, `details`, `blocked` (bool), `count` (int), `points` (int).
- `Punished` срабатывает на кик или бан. Ключи: `steam_id`, `nick`, `action` (`"kick"` / `"ban"`), `reason`.
- `IsBanned(ulong steamId)`, `GetPoints(ulong steamId)`, `Version`.

Обработчики выполняются в главном потоке, делайте их быстрыми. Порядок загрузки не важен, если подписываться через несколько секунд после старта или с повторными попытками.

## Сборка

Нужно: .NET 6 SDK или новее и папка игры с BepInEx 6 IL2CPP, запущенным хотя бы раз (чтобы появилась `BepInEx/interop`).

```
dotnet build -c Release -p:GameDir="C:\путь\к\SCP Project 90"
```

Без `-p:GameDir` сборка ищет `./libs` (та же структура: `libs/BepInEx/core`, `libs/BepInEx/interop`). DLL игры и BepInEx в репозиторий не входят.

### Перенос на новую версию игры

Все обфусцированные имена собраны в `src/P90Guard/Core/Game.cs`. После обновления игры:

1. Пересоберите interop-сборки (запустите сервер с BepInEx один раз).
2. Найдите новые имена методов из `Game.cs` (например, через Il2CppDumper или Cpp2IL и dnSpy). Методы `Invoke...` это инвокеры команд Mirror с сигнатурой `(NetworkBehaviour, NetworkReader, NetworkConnectionToClient)`.
3. Обновите константы, добавьте новый хэш `GameAssembly.dll` в `GameVersion.KnownHashes`, соберите и проверьте каждую проверку.

## Ограничения

- Проверяются только команды. Движение и прицел (спидхак, noclip, аимбот) в этой игре считает клиент, они не покрываются.
- `use_missing` и `heal_spam` по умолчанию в `Log`: игра может убрать расходник за мгновение до команды использования.
- Серверному плагину, который шлёт клиентские команды от имени игроков в обход обычного пути вызова, может понадобиться `DisabledPatches` или `Off` для соответствующей проверки.
